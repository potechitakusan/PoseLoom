PoseLoom 制作ツール

簡単な使い方：チェックアウトしたこのフォルダをCodexで開き、あとは使い方をCodexに聞いてください。

まず「AGENTS.mdを読んで、導入と使い方を教えてください」と伝えてください。作りたいものや利用環境を説明し、導入・操作は生成AIと相談しながら進められます。Codex以外のAIコーディングエージェントでも、AGENTS.mdを読ませてから相談できます。

人物画像の姿勢をBlenderの編集用人形へ適用し、BVH・Blend・HTMLカタログを作るローカルツールです。素材データは別配布です。

インストール・設定・コマンド · AIエージェント用の指示

python -X utf8 kit.py --help
python -X utf8 kit.py doctor --offline
  • prepare-models：基本Blendに埋め込んだ体形情報を制作環境へ取り出す
  • pose：画像からポーズを推定
  • retarget：対応する解析元FBXを人形へ適用
  • scene：JSONを使って背景へ人物を配置
  • export：保存したblendからBVHと、情報を埋め込んだ汎用Blendを書き出し
  • generate / batch：参照画像の生成とテーマ別の一括処理
  • catalog：公開用情報除去を行い、HTML・AI検索用JSON入りZIPを構築・検証
  • privacy：公開用コピーのローカル情報除去と検査
  • pair：二人の画像を分離・解析してシーンを組み立て
  • img2bvh：MediaPipeを使う任意の比較用パイプライン

このフォルダが公開kitのルートです。distはCloudflare Pages用、releasesはGitHub Releases用、maintenanceは非公開の保守用で、いずれもGit対象外です。配布構成・公開HTMLの更新手順・公開用情報除去とZIP内JSONを参照してください。
